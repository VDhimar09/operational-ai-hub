# Operational AI Hub

**A workflow orchestration dashboard exploring reliable, observable and human-governed AI operations.**

Operational AI Hub is a portfolio project focused on how operational workflows can be represented, simulated and monitored through a modern web interface. It brings together workflow visualisation, deterministic simulation and human approval to explore the foundations of reliable AI-enabled operations.

🔗 **Live demo:** [Operational AI Hub](https://operational-ai-hub.vercel.app)  
💻 **Source code:** [GitHub repository](https://github.com/VDhimar09/operational-ai-hub)

## Overview

AI-enabled operational systems need more than intelligent decisions. They also need clear execution states, human oversight, traceability and predictable behaviour when something goes wrong.

Operational AI Hub explores these ideas through an interactive dashboard and a local workflow simulation. The project is being developed iteratively, with an emphasis on maintainable code, automated testing and responsible implementation.

## Features

### Workflow visualisation

- Displays a sample operational workflow from trigger through analysis, risk assessment, human approval and resolution.
- Represents workflow stages with clear visual status indicators.
- Provides a workflow builder interface with sample workflow nodes.

### Deterministic workflow simulation

- Runs a predictable, local simulation of the sample workflow.
- Tracks the status of individual steps.
- Supports successful completion and simulated failure scenarios.
- Records workflow runs in session-level history.

### Human approval

- Pauses the simulation at a human approval step.
- Allows the user to approve or reject the simulated workflow.
- Stops downstream steps when approval is rejected.

### Failure handling and automated tests

- Handles injected workflow failures, including invalid failure-step identifiers.
- Records failure information through the simulation result.
- Includes automated tests for successful runs, rejected approvals, injected failures and workflows without an approval step.

> **Important:** Workflow execution is currently a local simulation. The application does not execute real operational actions or connect the displayed workflow to live enterprise systems.

## Technology Stack

The project uses the following technologies:

- **React** — component-based user interface
- **TypeScript** — typed application and simulation logic
- **TanStack Start** — application framework
- **TanStack Router** — file-based routing
- **Vite** — development and build tooling
- **Tailwind CSS** — interface styling
- **Lucide React** — interface icons
- **Node.js test runner** — automated simulation tests
- **ESLint** — code quality checks
- **Vercel** — deployment

## Getting Started

### Prerequisites

Install:

- Node.js and npm
- Git
- Visual Studio Code (recommended)

### Installation

Clone the repository:

```bash
git clone https://github.com/VDhimar09/operational-ai-hub.git
cd operational-ai-hub
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in the terminal.

### Run the checks

Run the automated tests:

```bash
npm test
```

Run lint:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

The lint command may report existing React Fast Refresh warnings in UI components. These should be distinguished from actual lint errors.

## Engineering Principles

The project follows several principles:

- **Deterministic behaviour:** identical simulation inputs should produce predictable outcomes.
- **Human oversight:** approval and rejection are explicit parts of the workflow.
- **Failure visibility:** unsuccessful execution should not be reported as successful completion.
- **Automated verification:** tests protect expected workflow behaviour against regressions.
- **Clear boundaries:** simulated behaviour is clearly distinguished from real operational execution.
- **Incremental development:** changes are validated with tests, lint and production builds.
